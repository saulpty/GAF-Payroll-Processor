## Decisions Saul made

- **Absent Days** = every absence, reported or not.
- **Avg Min Late** = over late days only (List's per-employee table and panel still
  average over days worked — `computeEmployeeStats` untouched, guarded by AC4).
- **Work Days** = every scheduled shift day, including time off and permission.
- **When payroll and Monday disagree about time off / permission, payroll wins**
  (option 1), plus the quiet flag (from option 2). Reasoning: one number per thing,
  payroll is where days get corrected, Monday mirror is only as fresh as the last sync.
- Only payroll's time-off and permission labels override. `Ausencia Injustificada`
  still goes through punches/forms, so a docked day with a form on file is still
  caught by `recordedUnexplainedButFormOnFile`.
- `Ausencia Justificada.` counts as **time off** on both tabs (that is what List
  always did). Its form still shows on the Reports tile.

## Why the tabs used to disagree (for the record)

List reads the label payroll wrote on each day. Reports ignored that label and
decided each day from punches + Monday requests/forms. Where payroll excused a
day but Monday had no request (or a request type Reports did not recognise),
Reports called it an absence. Q1-Sep-2026 before prompt 03: List 3 / 52 / 11
(absent / time off / permission), Reports 30 / 30 / 0.

## Still different, on purpose

**Reported / Unreported** differ slightly (List 88 / 110, Reports 95 / 103). List
counts a late day as reported only when payroll's `documentation` says a form was
filed; Reports looks for any Monday attendance form on the day. Not changed.
