## Lessons (also in UIB-GUIDE)
- UIB can silently "improve" a whole-file write: step 4b renamed List headers and dropped % On-Time
  sorting. Byte-compare every export with the draft (`diff --strip-trailing-cr`) — that is how it
  was caught; corrected by prompt 20, now guarded by test LP7.
- The Windows clipboard can be locked; feed prompts via `tools/serve-prompts.mjs` + fetch in the
  builder tab (see UIB-GUIDE).
- Prompts over ~40 KB: split (18 → 18 + 19). Use targeted one-line edits for tiny changes.
