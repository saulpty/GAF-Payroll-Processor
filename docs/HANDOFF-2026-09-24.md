## What changed

**Form app** (now mirrored in git under `form-app/`, synced with `tools/sync-export.mjs --app form`)
- No manager name/email boxes. Banner: "Filing as <name> (<login email>) · N employees".
- The filer is the UIB login (`loadCurrentFiler`, `{{ user.email }}`); `saveSubmission` writes
  `manager_email` from the login on the server and inserts nothing if nobody is signed in.
- A manager sees only employees whose Monday Manager 1-4 email is theirs (`filerScope.ts`).
  `disciplinary_admins` (Tim, Saul) see all current employees. The 40-name fallback list is gone.
- A failed save stays on the page with an error (it used to show "success" anyway).
- Default date is the local date (it showed tomorrow after 7 pm).

**Hub, Disciplinary page**
- **Download PDF** for everyone who can see a warning (stored PDF, or rebuilt from the row).
- **Edit** (Tim and Saul only): every box editable; **Save and email** rebuilds the PDF, saves,
  emails it marked UPDATED to the filing manager with Saul/Tim/Marcela CC'd, and offers
  **Download updated PDF**. The first PDF is kept: **Download original PDF** + "Edited by … on …".
- Delete / Restore / the Deleted filter are Tim and Saul only (were: all 8 super users). All four
  writes check `disciplinary_admins` in SQL with the login email, so the lock is server-side.
- "Email Passiontocare" was connected to the Hub (Saul approved) for the UPDATED email.
