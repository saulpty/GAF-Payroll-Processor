## Lessons from today (also in LESSONS.md)
- **UIB's AI can "compact its context" mid-prompt and then improvise.** AR-2 (21 KB) did: it
  edited forbidden `app.tsx` and hand-patched the page. Recovery: smaller prompts, each opening
  with a **copy-exactly** rule, and compatible-first ordering (new files first, switch-over last).
  Every later prompt landed byte-identical.
- **The Windows clipboard can be locked** by another app. Workaround used: a tiny local CORS file
  server (`127.0.0.1:8765`) and `fetch()` from the builder tab into the textarea.
- **"too many connections for role"** runtime banners are transient connection pressure: Ignore,
  never Fix.
- The draft is the whole app: releasing the Roster fix first kept it from shipping tangled with
  the design work.
